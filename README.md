# Movie-Ticket-Booking-System
A movie ticket booking system built using Python + Streamlit - includes theatre selection, date &amp; showtime booking, seat map and final ticket summary.

Features:
- Theatre Selection
- Date & Showtime Booking
- Dynamic seat map with aisle spacing
- Category-based pricing
- Payment flow
- Final ticket summary

Tech Stack
- Python
- Streamlit

This project was started as a terminal-based and was re-built into a web application.
